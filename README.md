# Trading Strategy Risk Analysis

Исследовательский проект по анализу риска и снижению просадок в алгоритмическом портфеле трендовых стратегий на криптовалютных бессрочных фьючерсах OKX.

Проект объединяет анализ закрытых сделок, восстановление плавающей PnL по 15-минутным свечам и проверку правил динамического управления риском. Это исследовательский код: результаты предназначены для проверки гипотез и не являются готовой торговой системой или инвестиционной рекомендацией.

## Текущие выполненные этапы

- измерить доходность и риск портфеля и отдельных стратегий;
- сравнить реализованную и плавающую кривые PnL;
- оценить MDD, DaR, CDaR, длительность просадок, Calmar, Recovery Factor, Sharpe и Sortino;
- проверить, насколько снижение или отключение риска отдельных стратегий уменьшает просадку портфеля;
- изучить компромисс между снижением максимальной просадки и сохранением прибыли;
- проверить фильтры по кривой капитала и правила динамического изменения размера позиции.

## Данные

Основной набор содержит сделки 93 стратегий по 21 инструменту. В репозитории используются две версии таблицы сделок:

- `data/deals_all_opt.csv` — исходная выборка закрытых сделок;
- `data/deals_all_opt_2026-09-11__risk_uniform.csv` — расширенная выборка с унифицированным риском;
- `data/candles/*_15m.csv` — 15-минутные OHLCV-свечи OKX, используемые для восстановления плавающей PnL.

Ключевые поля сделок: стратегия, инструмент, таймфрейм, направление, даты и цены входа/выхода, объём, комиссия, абсолютный PnL, PnL относительно капитала и размер капитала перед сделкой.

Даты сделок интерпретируются как UTC. Перед сравнением результатов следует явно проверить временную зону, полноту свечей и соответствие диапазонов сделок и рыночных данных.

Большие CSV-файлы и каталог свечей исключены из обычного Git через `.gitignore`. Для совместной работы их следует хранить отдельно, подключить DVC/Git LFS либо предоставить небольшой обезличенный пример данных.

## Что делает каждый ноутбук

### `01_portfolio_performance_analysis.ipynb`

Базовый анализ портфеля и стратегий: распределение сделок, денежная кривая капитала, доходность по периодам, MDD, DaR/CDaR, длительность просадок, Recovery Factor, Calmar, Sharpe и Sortino.

### `02_floating_pnl_analysis.ipynb`

Восстанавливает плавающую PnL открытых позиций по 15-минутным свечам, объединяет её с реализованным PnL и проверяет простые фильтры по кривой капитала: EMA и асимметричный канал.

### `03_drawdown_risk_management.ipynb`

Проверяет несколько правил управления риском: уменьшение размера новых позиций при ухудшении стратегии, выборочное ограничение стратегий, индивидуальные пороги MDD/DaR/CDaR, возврат риска после восстановления и отключение без возврата.

На текущей исторической выборке исследованные варианты уменьшали MDD, но также снижали итоговый PnL. В сохранённых результатах порог DaR 95% давал минимальную просадку, а CDaR 95% — более мягкую потерю прибыли. Это результат конкретной выборки, а не доказательство устойчивости метода вне неё.

## Быстрый старт

Проект использует окружение Miniconda/Conda, описанное в `environment.yml`.

### 1. Создать окружение

```bash
conda env create -f environment.yml
conda activate trading-risk-analysis
```

Если окружение уже существует, его можно обновить после изменения зависимостей:

```bash
conda env update -f environment.yml --prune
```

Для явного добавления окружения в список ядер Jupyter:

```bash
python -m ipykernel install --user \
  --name trading-risk-analysis \
  --display-name "Python (trading-risk-analysis)"
```

### 2. Подготовить данные

Перед запуском поместите таблицу сделок в `data/`:

```text
data/deals_all_opt.csv
data/deals_all_opt_2026-09-11__risk_uniform.csv
```

Загрузка или обновление 15-минутных свечей запускается из корня репозитория:

```bash
python okx_parser.py
```

Парсер читает `data/deals_all_opt.csv` и сохраняет свечи в `data/candles/`.

### 3. Запустить JupyterLab

Ноутбуки используют относительные пути вида `../data/...`, поэтому запускайте JupyterLab из каталога `notebooks/`:

```bash
cd notebooks
jupyter lab
```

В интерфейсе Jupyter выберите ядро `Python (trading-risk-analysis)`, если регистрировали его отдельной командой.

Рекомендуемый порядок знакомства с проектом:

1. `01_portfolio_performance_analysis.ipynb`
2. `02_floating_pnl_analysis.ipynb`
3. `03_drawdown_risk_management.ipynb`
